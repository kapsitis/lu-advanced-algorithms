# General Guidelines for the C++ Problems

1. Create a single C++ file matching the exercise name `matrix-max.cpp` etc. 
2. Use arrays, pointers and variables of basic types. 
   Do not use external data-structure libraries (such as STL, Boost, etc.). 
3. I/O libraries -- `iostream`, `sstream`, `iomanip` are fine. 
4. Place all the files in the directory `ds-workspace-YourName/cpp-problems`.
5. Commit and push your repository to GitHub. Tag this programming task as `lab1`.
