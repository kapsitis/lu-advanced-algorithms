## Maximum Element in a 2D Array

1. Create a C++ program that reads an $3 \times 5$ array of integers from the standard input.
2. It scans this array in the row-major order and finds the maximum value. 
3. It outputs this maximum value, its row and column number (starting from index 0). 
4. If maximum repeated multiple times, output the last position where it was encountered. 

**Sample input**

``` text
3 5
4 6 7 2 5
6 7 0 4 4
5 7 3 6 1
```

**Sample output**

``` text
7 2 1
```
