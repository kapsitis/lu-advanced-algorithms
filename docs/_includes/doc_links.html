{%- comment -%} Inline "[web], [pdf], [docx]" links for a page, given its permalink: {% include doc_links.html url="/matf78/26_27/78STRUCT_solution_structure/problems/" %} [web] points to the permalink. [pdf]/[docx] point to the files named like scripts/convert_directory.py does it: the source .md path joined with '-', with school years "26_27" expanded to "2026_27", placed next to the .md, e.g. /matf78/26_27/78STRUCT_solution_structure/matf78-2026_27-78STRUCT_solution_structure-problems.pdf The source path is looked up via the permalink (so class1.md with permalink .../handout_class1/ still yields ...-class1.pdf); if no page has that permalink, the permalink itself is used as the path. A language-neutral URL (a lang_redirect stub, e.g. /lectures/lossy_images_and_audio/jpeg_lab/) is replaced by the version in the current page's language (.../jpeg_lab/lv/, source index.lv.md -> ...-jpeg_lab-index.lv.pdf). {%- endcomment -%} {%- assign web_url = include.url -%} {%- assign doc = site.pages | where: "url", web_url | first -%} {%- if doc.layout == "lang_redirect" -%} {%- comment -%} Language-neutral URL: use the version in the current page's language. {%- endcomment -%} {%- assign web_url = web_url | append: page.lang | append: "/" -%} {%- assign doc = site.pages | where: "url", web_url | first -%} {%- endif -%} {%- if doc -%} {%- assign src = doc.path | remove: ".md" -%} {%- else -%} {%- assign src = include.url -%} {%- endif -%} {%- assign parts = src | split: "/" -%} {%- assign dir = "" -%} {%- assign full = "" -%} {%- assign stem = "" -%} {%- for part in parts -%} {%- if part == "" -%}{%- continue -%}{%- endif -%} {%- assign dir = full -%} {%- assign full = full | append: "/" | append: part -%} {%- assign piece = part -%} {%- assign third = part | slice: 2 -%} {%- if part.size == 5 and third == "_" -%}{%- assign piece = part | prepend: "20" -%}{%- endif -%} {%- if stem != "" -%}{%- assign stem = stem | append: "-" -%}{%- endif -%} {%- assign stem = stem | append: piece -%} {%- endfor -%} {%- assign base = dir | append: "/" | append: stem -%} [web]({{ web_url | relative_url }}), [pdf]({{ base | append: ".pdf" | relative_url }}), [docx]({{ base | append: ".docx" | relative_url }}) {%- comment -%} no trailing newline, so the include can sit inside a list item {%- endcomment -%}
