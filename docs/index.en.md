# Algorithms in Telecommunications and Security Solutions

**Description:** This seminar complements the course "Applied Algorithms" 
(DatZ4020 / DatZB060) in years when that course is not taught. We study algorithms 
for lossless compression (arithmetic coding, Asymmetric Numeral Systems (ANS), 
Lempel–Ziv, Burrows–Wheeler), audio and video formats, error correction 
(Hamming, Reed–Solomon), string searching (KMP, Boyer–Moore, suffix trees, 
hashing and Bloom filters), linear programming algorithms (duality and 
relaxation of integer programs), and aspects of using cryptographic algorithms 
and standards. 

**Requirements:** Each participant chooses a family of algorithms or a standard, 
studies its mathematical foundations, builds a prototype and test data, 
performs measurements, and presents the results.
