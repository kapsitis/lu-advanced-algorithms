# Algoritmi telekomunikācijās un drošības risinājumos

**Apraksts:** Specseminārs papildina kursa "Lietišķie algoritmi" 
(DatZ4020 jeb DatZB060) tematiku gados, kad to nemāca. Aplūkojam algoritmus 
bezzudumu saspiešanai (aritmētiskā saspiešana, Asymmetric Numeral Systems (ANS), 
Lempel-Ziv, Burrows–Wheeler), audio un video formātus, kļūdu korekciju 
(Hamming, Reed-Solomon), virkņu/stringu meklēšanu (KMP, Boyer-Moore, suffix trees, 
hashing and Bloom filters), lineārās programmēšanas algoritmus (dualitāti un 
veselo skaitļu uzdevumu relaksāciju), kriptoalgoritmu un standartu 
izmantošanas aspektus. 

**Prasības:** Katrs dalībnieks izvēlas algoritmu saimi vai standartu, 
izpēta tā matemātisko pamatojumu, izveido prototipu un testa datus, 
veic mērījumus un prezentē.

**Title:** Algorithms in Telecommunications and Security Solutions

**Description:** This seminar complements the course "Applied Algorithms" (DatZ4020 / DatZB060) in years when the course is not offered. We cover algorithms for lossless compression (arithmetic coding, Lempel-Ziv, Burrows–Wheeler), sound, audio and video formats, error correction (Hamming, Reed-Solomon), string searching (KMP, Boyer-Moore, suffix trees, hashing and Bloom filters), linear programming algorithms, as well as practical aspects of using cryptographic algorithms and standards. Each participant chooses a family of algorithms or a standard, studies its mathematical foundations, builds a prototype and test data, performs measurements, and presents the results.
